## Socket.IO y arranque del servidor

Al agregar chat con Socket.IO se usa Express como aplicación y un servidor HTTP compartido para Socket.IO. El flujo es:

- `const app = express();` → configura Express y rutas.
- `const server = http.createServer(app);` → crea el servidor HTTP que sirve a Express.
- `const io = new Server(server);` → conecta Socket.IO a ese servidor HTTP.
- `server.listen(PORT, ...)` → arranca el servidor HTTP compartido.

De esta forma, `app` sigue usándose para Express, pero el puerto se abre con `server.listen(...)` porque Socket.IO necesita el mismo servidor HTTP.
### Ejemplo de arranque con Socket.IO

```js
import express from "express";
import http from "http";
import { Server } from "socket.io";

const app = express();
const server = http.createServer(app);
const io = new Server(server);

app.use(express.json());
app.set("view engine", "pug");

app.get("/", (req, res) => {
  res.redirect("/auth/login");
});

io.on("connection", (socket) => {
  console.log("Usuario conectado");
  socket.on("mensaje", (mensaje) => {
    io.emit("mensaje", mensaje);
  });
});

const PORT = process.env.PORT || 3000;
server.listen(PORT, () => {
  console.log(`Servidor corriendo en http://localhost:${PORT}`);
});
```

## Ejemplo simple de frontend Socket.IO

En tu plantilla Pug o HTML, incluye el cliente de Socket.IO y un formulario básico:

```pug
html
  head
    title Chat
    script(src="/socket.io/socket.io.js")
    script.
      const socket = io();
      function enviarMensaje() {
        const input = document.getElementById('mensaje');
        socket.emit('mensaje', input.value);
        input.value = '';
      }
      socket.on('mensaje', (mensaje) => {
        const lista = document.getElementById('mensajes');
        const item = document.createElement('li');
        item.textContent = mensaje;
        lista.appendChild(item);
      });
  body
    h1 Chat en tiempo real
    ul#mensajes
    input#mensaje(type='text' placeholder='Escribe un mensaje...')
    button(type='button' onclick='enviarMensaje()') Enviar
```

Con esto el navegador se conecta a Socket.IO, envía mensajes con `socket.emit('mensaje', ...)` y recibe mensajes con `socket.on('mensaje', ...)`.
